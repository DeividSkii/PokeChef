# 🍽️ PokeChef – Pokémon + Receitas via API

O **PokeChef** é um projeto que integra **duas APIs REST simultaneamente**:

- **PokeAPI** – dados completos de qualquer Pokémon  
- **TheMealDB** – receitas relacionadas ao tipo do Pokémon pesquisado  

O usuário digita o nome de um Pokémon, o sistema identifica seu **tipo**, converte esse tipo em um **tema culinário**, e retorna uma **receita temática compatível**.

O projeto segue os princípios de **Mobile First**, utiliza **DOM**, `fetch()`, **Node.js + Express**, arquitetura REST e documentação clara.

---

## 🚀 Funcionalidades

- Buscar qualquer Pokémon pelo nome  
- Exibir imagem, tipo, ID, altura e peso  
- Converter tipo do Pokémon para tema culinário  
- Buscar receita baseada no tipo usando TheMealDB  
- Exibir nome, foto, categoria e origem da receita  
- Mostrar instruções resumidas e link para versão completa  
- Interface responsiva e visual agradável
